# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability** ([lien direct](https://github.com/Tostenn/Quelbus/security/advisories/new)).

Indiquez si possible :

- la partie concernée (`front/`, `back/`, déploiement) ;
- les étapes pour reproduire le problème ;
- l'impact possible (fuite de données d'inscription, déni de service, etc.).

Nous accusons réception sous 7 jours et vous tenons informé de la correction. Nous citons volontiers les personnes qui signalent une faille, si elles le souhaitent.

## Versions prises en charge

Le projet est en phase de lancement : seule la branche `main` reçoit des correctifs de sécurité.

## Données personnelles

Le formulaire d'inscription collecte prénom, nom et adresse email. Ces données ne doivent jamais apparaître dans le dépôt, les issues, les journaux publics ou les captures d'écran.
